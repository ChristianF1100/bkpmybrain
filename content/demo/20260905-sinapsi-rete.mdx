L'idea è semplice: ogni contenuto è un nodo, i tag creano i collegamenti e l'attività decade col tempo. Il cuore è una funzione pura:

```ts
// attività di un nodo = 1 − Π(1 − contributo)
export function accumulate(contributions: number[]): number {
  return 1 - contributions.reduce((rem, c) => rem * (1 - c), 1);
}
```

Tutto il calcolo avviene nel browser: nessun server, nessun database.
